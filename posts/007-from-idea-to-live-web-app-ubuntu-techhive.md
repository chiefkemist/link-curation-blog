# From Idea to Live Web App: Building with Humans and AI Agents on Buzz

This Ubuntu TechHive event describes a beginner-friendly live build using Buzz as the shared workspace for humans and AI agents. The session starts with an intentionally incomplete product brief, then moves through research, design, implementation, review, and deployment of a browser-based application.

The agenda emphasizes the collaboration trail as much as the final software: participants can follow the brief, delegated work, design decisions, rejected ideas, agent contributions, and human approvals in Buzz. The event is aimed at developers, learners, open-source builders, community members, and beginners who want to understand agent collaboration through a concrete project. No prior Buzz, Nostr, or AI-agent experience is required.

The event page promises a public deployment during the session, but intentionally withholds the exact application and framework so the audience can watch the product take shape.
